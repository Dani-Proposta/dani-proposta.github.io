## Objetivo

Desenvolver uma plataforma pessoal para apresentar
serviços, habilidades e projetos profissionais.

## Arquitetura

O site utiliza Astro com geração estática, componentes
reutilizáveis e dados organizados separadamente
da apresentação visual.

## Hospedagem

O projeto é publicado no GitHub Pages, utilizando
GitHub Actions para automatizar o processo de build
e deploy.

## Evolução

O sistema está sendo desenvolvido para permitir
a inclusão de novas áreas profissionais, projetos
e estudos de caso sem reconstruir as páginas existentes.
